# 全网比价混合体验设计

## 设计定位

这是一个面向旅行决策的比价页面：用专业工具的信息层级帮助用户快速比较，用旅行杂志式图片和编辑内容增强目的地感。页面保持一个主色调和统一圆角体系，避免把比价结果做成无差别的数据表。

## 结果卡片

- 顶部使用酒店主图作为视觉入口，图片优先使用发布者上传图片，其次使用供应商图片，最后使用统一默认酒店图。
- 图片使用渐变遮罩，确保酒店名称、评分和价格在不同图片上都有足够对比度。
- 首屏突出最低价、价格单位、平台、入住条件、取消政策和实时/估算状态。
- 次级信息展示位置、房型、面积、早餐、设施等可影响决策的内容。
- 价格和预订按钮保持右侧固定层级，移动端改为底部横向操作区。

## 详情内容

- 详情页主图使用发布者图片轮播，无图时回退默认图。
- 内容顺序为：价格与来源、房型政策、位置与周边、设施、用户内容、预订入口。
- 实时数据和 fallback 数据必须明确标记，不把估算价格显示成实时价格。
- 图片加载失败时替换为默认图，并保留可访问的 `alt` 文本。

## 数据契约

`CompareItem` 增加可选 `image` 和 `images` 字段；RollingGo 供应商字段映射只接受有效的 HTTP(S) 图片地址。前端统一使用图片选择器处理优先级和 fallback，避免每个页面重复实现。

## 状态与性能

- 搜索中使用与结果卡片同形状的骨架屏，不用单独的空白转圈。
- 空结果说明搜索条件并提供修改入口；错误状态保留重试。
- 图片使用 `loading="lazy"`、尺寸约束和错误回退，避免 CLS 和破图。
- 保留现有缓存和 `dataSource` 字段；不因 UI 改造绕过后端真实数据降级逻辑。

## 验收标准

- 有发布者图片时，搜索卡片和详情页优先显示该图片。
- 供应商或发布者无图、图片 URL 无效、图片加载失败时均显示默认图。
- 价格、平台、日期、取消政策和数据来源在桌面与移动端可直接识别。
- TypeScript、单元测试和生产构建通过。
